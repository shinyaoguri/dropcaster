プロジェクトに入れた OpenProcessing・Gist の作品のコードを固定できるようにした。固定した作品は、作者が作品を更新しても「保存した作品を開く」で固定時のコードを開き、「最新版を取得」を押したときだけ新しいコードに切り替わる（取得に失敗したら固定したコードをそのまま使う）。

固定するのはコードだけで、画像・音などの素材は取得元から読み込む。固定したコードはこのブラウザにだけ保存し、パッケージの書き出しには作品の参照と照合用の hash だけを入れる。受け取った側で内容が違えば、その旨を表示して固定し直せる。版を確実に固定して持ち運ぶには、ギャラリーに `dropcaster fetch` で取り込む方法を README で案内している。
