# 0013: 基本立体の会場編集と観察専用の投影ガイド

## 状態

採用（2026-11-12 JST）。#134 / #135。[0011](0011-measured-venue-authoring.md) の部材と保存形式、
[0012](0012-unified-mapping-workspace.md) の上部操作を拡張する。

## 文脈

利用者はdropcaster内で簡単な平面立体を組み合わせ、会場を配布して他のユーザーに再構築してほしい。
複雑なモデリングは不要。普段のマッピングを圧迫しないよう、低頻度の会場操作を控えめにする。
3Dでは会場に映る映像だけでなく、プロジェクタの位置と向き・画角を視覚的に確認したい。

## 決定

- 個別作品とスライドショーの入口は四隅と歪んだグリッドの共通SVGにする。
- 上部は「設定・共有」のdisclosureと閉じるアイコンに整理する。メニューは3D設定、会場編集、
  保存・共有への入口。開閉だけでThree.jsを読み込まない。Escape・外側クリックで閉じる。
- 会場の部材は壁・床・箱・四面体（三角すい）・三角柱。全て平面で構成し、寸法は回転前の
  外接直方体、位置はその中心。メートル単位の寸法・位置・回転・色を編集し、複製できる。
  部屋のひな形に加え、箱1つからも開始できる。既存と同様に直前の会場変更へ戻せる。
- 会場編集内で書出・読込を提供する。ファイルは形状・投影条件・2Dマッピングを含み、
  他のユーザーの作品・再生設定を変更せずに会場を復元する。
- Project v3 / Venue v2を出力する。Project v1/v2、Venue v1、旧2D JSON、GLBは読む。
  新立体を旧バージョンに偽装したデータは拒否し、旧クライアントで形状を黙って失わない。
- 投影ガイドは簡略化した本体、光軸の原点から4隅への線、薄い範囲面を表示する。
  実際の投影行列の逆行列を使い、画角・アスペクト・レンズシフト・姿勢へ追従させる。
  表示の奥行きは会場外接箱の最遠深度（描画範囲内）まで。光量や実際の照射面積の計算ではない。
- ガイド全体を観察専用レイヤに置く。観察カメラだけがこのレイヤを表示し、投影カメラの
  固定背景・深度パス、compositor、実出力には入れない。表示を切り替えられ、GPU資源を終了時に解放する。

## 影響

外部3Dツールを使わずに基本的な会場作成・配布が完結する。頂点編集、曲面、複数プロジェクタの
同時投影は範囲外。元映像の解像度、CSS投影、同一オリジンiframe、streamの所有権は変更しない。

新形状の寸法・面方向・閉じた形状、ガイドの投影行列との一致とレイヤ分離を単体テストで検証する。
両viewerでガイド有無による背景・composite・遮蔽結果の一致、メニュー、会場ファイルの配布・再編集、
旧保存データの移行を回帰確認する。
