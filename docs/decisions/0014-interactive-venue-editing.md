# ADR 0014: 会場のGUI編集を1ドラッグ単位の操作にする

## 状態

採用（2026-11-12、#136）。編集操作・保存形式は継続。画面の配置は [0015](0015-standalone-venue-calibration.md) で独立した会場調整画面へ移行。

## 文脈

実寸フォームと単純立体による会場作成はあるが、空間の配置をGUIで組み立てたい。
既存の2D出力・ストリーム・共有ファイルを維持し、複雑なモデラーにはしない。

## 決定

- 「設定・共有」→「会場を編集」で3D右ペインの編集ツールを表示する。通常の3D観察は従来通り。
- Raycasterで部材を選択し、Three TransformControlsで移動・回転・サイズを操作する。
  移動は世界座標、回転と寸法は部材座標。数値入力と選択を共有する。
- 操作の対象は軽量なproxy。ドラッグ中は描画メッシュと遮蔽だけを更新し、pointerupで1回ProjectSessionに確定する。
  Escape、pointercancel、capture喪失、blur、タブ非表示、モデル置換、終了では保存せず復元する。
  「会場変更を戻す」でドラッグ全体を戻せる。一般的な多段undoは#118の範囲。
- ハンドル・選択枠はobserver専用layer 1。実出力・固定背景・投影深度には含めない。
- 寸法は正の実寸へ変換し、既存スキーマの上限・下限を守る。Project v3 / Venue v2の変更はない。
- サンプルとGLBを編集開始だけで置き換えない。箱/部屋からの開始は明示操作とし、直前の会場へ戻せる。

## 影響

既存会場の受信後も同じGUIで編集できる。頂点・曲面・ブーリアン編集は含めない。
移動・回転・サイズ変更とカメラ操作の競合を実ブラウザのポインタテストで確認する。
GPUリソースとイベントをパネル終了時に破棄し、配信トラックの所有権はWindowControllerのまま保つ。
