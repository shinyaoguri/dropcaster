# 0007: マッピングの quad は凸四角形に限り、隅の移動を凸の範囲へ制限する

- **状態**: 採用（2026-11-10）
- **文脈**: マッピングの映像は、矩形を quad へ写す射影変換（ホモグラフィ）を CSS `matrix3d` で当てて描いている（手動コーナーピン。[0003](0003-manual-corner-pin-over-camera-calibration.md)）。射影変換は凸な矩形を必ず凸四角形へ写すので、**凹んだ quad・自己交差した quad には正しい写像が存在しない**。それでも 4 隅の条件から係数は解けてしまい、同次座標の分母 `w` が映像の内部で符号を変える。ブラウザは `w < 0` の部分を反転した位置に描くため、隅を動かして quad を凹ませると映像が quad の外側へ回り込み、塗られる面が反転して見えた（[#95](https://github.com/shinyaoguri/dropcaster/issues/95)）。
- **決定**: quad は凸四角形に限る。
  - 隅のドラッグ・矢印キーでの移動は `constrainQuadCorner`（`src/viewer/utils/mappingTransform.ts`）を通し、quad が凸で、かつ**遠近の強さ（`w` の 4 隅での最大 / 最小）が 20 倍以下**に収まる範囲のうち目標にいちばん近い点へ寄せる。限界を越えて引っぱると隅は境界に沿って滑る
  - 遠近の強さで限る理由（2026-11-10 改訂。[#97](https://github.com/shinyaoguri/dropcaster/issues/97)）: 当初は「凸の境界から 1 仮想キャンバス px 内側」で止めていたが、凸であっても境界すれすれではホモグラフィがほぼ特異になる。報告された配置では `w` の比が約 800 倍になり、2px の枠線が約 520px に引き伸ばされて quad の広い範囲を塗り、隅が 0.25px 動くだけで映像の中の点が約 54px 動いてチラついた。比が 20 倍なら枠線は 29px、映像の動きは 0.17px に収まる（50 倍では 68px・0.95px で、枠線の帯がまだ目に付く）。台形でいえば平行な 2 辺の長さが 20:1 で、キーストーン補正には十分に広い
  - `w` の 4 隅での値は、反対側の隅の「角の三角形」（その隅と両隣の 3 点）の面積に比例する。この面積は動かす隅の位置の 1 次式なので、条件は半平面の共通部分（凸多角形）になり、最近点が一意に決まる。凸であることもこの条件に含まれる
  - 凸でない quad（[#95](https://github.com/shinyaoguri/dropcaster/issues/95) 以前に保存された設定など）は、描画時（`applyQuadCanvas`）に退化 quad と同じく非表示にし、反転した映像は出さない。そうした quad は隅の移動を制限しないので、隅を動かして凸に戻せる
  - 遠近の強さがすでに 20 倍を超えている quad（1px 余白の頃に保存された設定など）は、そのまま描く。隅を動かすときは 20 倍の代わりに「いまより強くしない」を条件にするので、触った隅が飛ばず、動かせば直せる
  - 向きは時計回り・反時計回りどちらも合法（左右・上下に反転させた quad は射影変換で正しく写せる）
- **影響**:
  - 断念した代替: 凹んだ quad をメッシュ分割（三角形ごとのアフィン変換や WebGL mesh warp）で描く。凹形を描けるようになる代わりに、凸のときの見た目まで射影変換と変わってしまう（パースの付き方が変わる）。プロジェクタのキーストーン補正に凹形は要らないので採らない。凹形の投影面が必要になったら、quad の変形ではなくマスク（多角形）で覆うか、mesh warp の再検討（[0003](0003-manual-corner-pin-over-camera-calibration.md) の影響節）から入る
  - 隅を個別に動かす経路を新しく足すとき（数値入力など）は、必ず `constrainQuadCorner` を通すこと。平行移動・回転・正の倍率の拡縮は凸性も遠近の強さも保つので不要
  - 三角形に近い quad（1 つの隅を対角線すれすれまで寄せた形）は作れない。三角形の面へ投影したいときは、quad は面を覆う大きさにしてマスクで切る
  - 上限を変えるときは `MAX_PERSPECTIVE_RATIO` の 1 か所。緩めるほど限界位置での枠線の引き伸ばしと映像の揺れが増える（上の数値）
  - マスク（SVG 多角形、`fill-rule: nonzero`）は射影変換を使わないので、凹形・自己交差を許してよい
