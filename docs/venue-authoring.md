# 実際の会場を作り、他のユーザーに渡す

[マッピング](https://dropcaster.soui.dev/mapping)を開き、上部の **「会場を作る」** を押す。
GLBを用意しなくても、壁・床・箱を組み合わせて会場やステージを作れる。
作業はこのブラウザへ自動保存する。配布・バックアップにはファイルを書き出す。

## 1. 会場を測り、基準を決める

単位はメートル。Xは左右、Yは高さ、Zは前後。床上面をY=0、投影先を−Z側、客席側を＋Zとする。
部屋の左右・前後の中央がX=0、Z=0。プロジェクタを置く位置もこの同じ基準から測る。

まず会場の**内寸**（幅・高さ・奥行き）、次に投影対象や遮蔽物の寸法・中心位置を測る。
写真から実寸を推定する機能ではない。壁の凹凸や柱は追加の箱で表せる。

## 2. 部屋と部材を作る

1. 「部屋の寸法から作る」に内寸を入力し、「この寸法で会場を作る」を押す。
   床と奥・左右の壁ができる。手前と天井は開放。既存の会場モデルを置き換えるが、マッピングと投影条件は保つ。
2. 「編集する部材」で対象を選び、名前・寸法・中心位置・回転・色を入力する。
   X方向が幅、Y方向が高さ、Z方向が奥行き。入力を確定すると固定背景と3Dビューへ反映する。
3. 壁・床・箱を追加し、必要に応じて複製・削除する。部材は最大128個。最後の1個は削除できない。
   「会場変更を戻す」で直前の会場変更を戻せる。
4. 3Dビューをドラッグして形を確認する。大きな会場に変えたら「全体」で画面に収める。

位置は**部材の中心**。床の上に置く高さ0.6mのステージなら、中心Yは0.3mにする。

| 例 | 寸法 X / Y / Z（m） | 中心 X / Y / Z（m） |
|---|---|---|
| ステージ | 2 / 0.6 / 1.2 | 0 / 0.3 / −1 |
| 柱 | 0.4 / 3 / 0.4 | −2 / 1.5 / 0 |
| 厚さ10cmの床 | 8 / 0.1 / 6 | 0 / −0.05 / 0 |

部屋のひな形は壁厚15cmを内寸の外側、床厚10cmをY=0の下に置く。「会場の寸法」は部材全体の
外形なので、入力した内寸に壁・床の厚みが加わる。個別部材を動かした後に部屋を作り直すと、
その編集はひな形で置き換わる。部材の寸法は直接メートルで扱い、GLB用の全体倍率はかけない。

## 3. 投影条件を合わせる

「3D設定」で実機に合わせた位置・回転・縦画角・アスペクト比・レンズシフトを設定する。
部屋の作成だけではプロジェクタの位置や画角は変わらない。遠い会場では描画範囲の「奥の距離」も確認する。
固定背景の輪郭に合わせ、従来の四隅・crop・maskを調整する。

3Dは選択した1台分の形状・歪み・遮蔽確認用。観察視点を回しても投影位置は変わらない。
実際の光量・反射・レンズ歪みを再現するものではない。

## 4. 会場を配布する

1. 「プロジェクト」で分かりやすい名前を付ける。
2. **「会場だけを書き出す」** を押す。`名前.venue.json` がダウンロードされる。
3. そのファイルを他のユーザーへ渡す。形状・投影条件・マッピングを含み、作品参照や再生順序、
   端末固有のディスプレイ配置は含まない。GLB会場の場合はモデルと埋込画像も含む。

作品参照やスライドショーも含むバックアップには、従来の「パッケージを書き出す」を使う。
会場ファイルはメール添付など任意の方法で配れる。アプリからの公開・クラウド同期は行わない。

## 5. 受け取った人が使う

自分の作品またはスライドショーで「マッピング」を開き、「プロジェクト」→
**「プロジェクト・会場・旧JSONを読む」** で会場ファイルを選ぶ。
現在の作品・再生設定を保ちながら、会場・投影条件・マッピングを読み込む。
作成された壁・床・箱は受信側でも編集できる。不正なファイルは現在の会場を置き換えない。

作品がまだなければ、[内蔵サンプル](https://dropcaster.soui.dev/mapping)から始められる。
[8m×6mの会場サンプル](samples/room-8x6.venue.json)はそのまま取り込める。

新しい保存形式は Project v2 / Venue package v1。配布先も最新版を使う。
以前のProject v1、旧2D設定v2、GLBの読込は継続して対応する。
曲面や複雑な模型が必要な場合は、外部の3Dツールで作った静的GLBを既存の会場読込から使える。
