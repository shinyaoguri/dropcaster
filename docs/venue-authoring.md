# 実際の会場を作り、他のユーザーに渡す

[会場の作成・調整](https://dropcaster.soui.dev/venue)を開く。ホーム、またはマッピングの
**「設定・共有」→「会場の作成・調整」** からも開ける。マッピングからは別タブで開き、現在の作品を続けられる。
GLBを用意しなくても、壁・床・箱・四面体・三角柱を組み合わせて会場やステージを作れる。
p5.jsの作品は読み込まず、実プロジェクタへ調整用の映像を出しながら、実物と3Dモデルを一致させるための画面。
作業はこのブラウザの**会場専用の下書き**へ自動保存する。マッピング側へ反映する際はファイルを書き出して読み込む。
「保存・読込」→「マッピングの会場をコピー」で以前の会場を引き継げる。元の作品・マッピング・下書きは変更しない。

## 1. 会場を測り、基準を決める

単位はメートル。Xは左右、Yは高さ、Zは前後。床上面をY=0、投影先を−Z側、客席側を＋Zとする。
部屋の左右・前後の中央がX=0、Z=0。プロジェクタを置く位置もこの同じ基準から測る。

まず会場の**内寸**（幅・高さ・奥行き）、次に投影対象や遮蔽物の寸法・中心位置を測る。
写真から実寸を推定する機能ではない。壁の凹凸や柱は追加の箱で表せる。

## 2. 部屋と部材を作る

1. 箱1つから始めるなら「箱1つの会場で作り直す」。部屋から始めるなら「部屋の寸法から作る」に内寸を入力し、「この寸法で会場を作る」を押す。
   床と奥・左右の壁ができる。手前と天井は開放。既存の会場モデルを置き換えるが、マッピングと投影条件は保つ。
2. 3Dビュー上の立体をクリックして選び、「移動」「回転」「サイズ」を選んで色付きハンドルをドラッグする。
   赤=X、緑=Y、青=Z。移動は会場の軸、回転・サイズは立体自身の軸に沿う。サイズは中心を保って変わる。
   小さい部材は「選択に寄る」で拡大する。「スナップ」を有効にすると移動は0.1m、回転は15°刻みになる。
   手を離すと確定・自動保存。Esc、別タブへの移動、画面の終了は操作中の変更を取り消す。
   正確な寸法・位置・角度や名前・色は左側の数値欄で微調整できる。選択は3Dと左側で共通。
   X方向が幅、Y方向が高さ、Z方向が奥行き。変更は投影するモデルの輪郭にも反映する。
3. 「追加する形」で壁・床・箱・四面体・三角柱を選び、「追加」を押す。必要に応じて複製・削除する。部材は最大128個。最後の1個は削除できない。
   「会場変更を戻す」で直前の会場変更を戻せる。
4. 空いた場所をドラッグして視点を回す。大きな会場に変えたら「全体」で画面に収める。
   「編集完了」でハンドルと編集ツールを閉じる。再開はビュー上部の「会場を編集」。
   ハンドルと選択枠は確認用で、実出力・投影背景には入らない。

既存のサンプルやGLBは、編集を開いただけでは置き換わらない。GUIで部材を組み立てるには
箱または部屋から始める。自作・受信した部材の会場は、そのままGUIで再編集できる。

四面体は三角すい、三角柱はY方向に頂部がある形。寸法は回転前の外接直方体の幅・高さ・奥行き、
位置はその**外接直方体の中心**。曲面や頂点単位の編集は使わない。

位置は**部材の中心**。床の上に置く高さ0.6mのステージなら、中心Yは0.3mにする。

| 例 | 寸法 X / Y / Z（m） | 中心 X / Y / Z（m） |
|---|---|---|
| ステージ | 2 / 0.6 / 1.2 | 0 / 0.3 / −1 |
| 柱 | 0.4 / 3 / 0.4 | −2 / 1.5 / 0 |
| 厚さ10cmの床 | 8 / 0.1 / 6 | 0 / −0.05 / 0 |

部屋のひな形は壁厚15cmを内寸の外側、床厚10cmをY=0の下に置く。「会場の寸法」は部材全体の
外形なので、入力した内寸に壁・床の厚みが加わる。個別部材を動かした後に部屋を作り直すと、
その編集はひな形で置き換わる。部材の寸法は直接メートルで扱い、GLB用の全体倍率はかけない。

## 3. 投影条件を合わせる

1. 「出力解像度」を実機のネイティブ解像度に合わせる（1920×1080、1280×800、1024×768）。
   左の **「プロジェクタ」** タブで投影アスペクト比も合わせる。
2. **「プロジェクタ出力を開く」** を押し、開いた別窓をプロジェクタ側のディスプレイへ移動して全画面にする。
   「グリッド・十字」や「白」で投影範囲を確認する。「黒（ブラックアウト）」は出力を黒にする。
3. 「モデルの輪郭」に戻し、実機に合わせて位置・回転・縦画角・レンズシフトを設定する。
   実際に投影された白い輪郭が、壁・床・立体の辺に重なるよう調整する。
   その後「立体」タブで実測値やGUIハンドルを使って形状を微調整する。
4. **「投影される像」** タブでは実出力と同じ像を手元でも確認できる。
   「3D会場」の観察視点を回しても投影位置は変わらない。操作ハンドル・選択枠・プロジェクタのガイドは投影しない。
5. 調整が終わったら **「出力を閉じる」** を押す。別窓を閉じたり、この会場画面を離れたときも調整用出力は終了する。

部屋の作成だけではプロジェクタの位置や画角は変わらない。遠い会場では描画範囲の「奥の距離」も確認する。
水色のガイドは位置・向き・投影範囲の目安。「全体」でガイドごと画面に収められる。
出力窓を拡大しても映像のピクセル数は変わらない。出力解像度は画面を開くたび1920×1080から始まる。
複数出力を含む会場は「プロジェクタ」タブで選択する。調整用出力は選択した1台分。

調整用の輪郭は仮想プロジェクタから見た形をそのまま出力する。保存済みの2D四隅・crop・maskで変形させない。
モデルと投影条件を合わせた後、通常のマッピングで作品の四隅・crop・maskを調整する。
実際の光量・反射・レンズ歪みを再現する機能ではない。

## 4. 会場を配布する

1. 「保存・読込」で会場に分かりやすい名前を付ける。
2. 画面右上の **「会場だけを書き出す」** を押す。`名前.venue.json` がダウンロードされる。
3. そのファイルを他のユーザーへ渡す。形状・投影条件・マッピングを含み、作品参照や再生順序、
   端末固有のディスプレイ配置は含まない。GLB会場の場合はモデルと埋込画像も含む。

作品参照やスライドショーも含むバックアップには、マッピング側の「パッケージを書き出す」を使う。
会場ファイルはメール添付など任意の方法で配れる。アプリからの公開・クラウド同期は行わない。

## 5. 受け取った人が使う

自分の作品またはスライドショーで「マッピング」を開き、「設定・共有」→「プレビュー設定」→
**「会場ファイルを読み込む」** で会場ファイルを選ぶ。「保存・共有」の読込ボタンも利用できる。
現在の作品・再生設定を保ちながら、会場・投影条件・マッピングを読み込む。
再調整するときは受信側も「会場の作成・調整」で読み込み、部材を追加・複製・編集できる。不正なファイルは現在の会場を置き換えない。

作品がまだなければ、[内蔵サンプル](https://dropcaster.soui.dev/mapping)から始められる。
[8m×6mの会場サンプル](samples/room-8x6.venue.json)はそのまま取り込める。

新しい保存形式は Project v3 / Venue package v2。配布先も最新版を使う。
以前のProject v1/v2・Venue package v1、旧2D設定v2、GLBの読込は継続して対応する。
曲面や複雑な模型が必要な場合は、外部の3Dツールで作った静的GLBを「会場の作成・調整」の「保存・読込」から使える。
