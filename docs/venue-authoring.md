# 実際の会場を作り、他のユーザーに渡す

[会場の作成・調整](https://dropcaster.soui.dev/venue)を開く。ホーム、またはマッピングの
左端のバーの「プロジェクト」パネルの一番下からも開ける。マッピングからは別タブで開き、現在の作品を続けられる。
GLBを用意しなくても、壁・床・箱・四面体・三角柱を組み合わせて会場やステージを作れる。
p5.jsの作品は読み込まず、実プロジェクタへ調整用の映像を出しながら、実物と3Dモデルを一致させるための画面。
作業はこのブラウザの**会場専用の下書き**へ自動保存する。マッピング側へ反映する際はファイルを書き出して読み込む。
画面はマッピングと同じ構成で、左端のアイコンで切り替えるツール列（立体・プロジェクタ・出力・ファイル・設定）、その右に
**「投影される像」**（実出力と同じ像）と **「3D会場」** が並ぶ。選択中のアイコンをもう一度押すとツール列を畳み、像と3D会場を広げる。
左端の「ファイル・設定」→「マッピングの会場をコピー」で以前の会場を引き継げる。元の作品・マッピング・下書きは変更しない。

## 1. 会場を測り、基準を決める

単位はメートル。Xは左右、Yは高さ、Zは前後。床上面をY=0、投影先を−Z側、客席側を＋Zとする。
部屋の左右・前後の中央がX=0、Z=0。プロジェクタを置く位置もこの同じ基準から測る。

まず会場の**内寸**（幅・高さ・奥行き）、次に投影対象や遮蔽物の寸法・中心位置を測る。
測る代わりに、プロジェクタから壁に映した十字で実物の角をなぞって作ることもできる（[測らずに作る](#測らずに作る実物の角をなぞる)）。
壁の凹凸や柱は追加の箱で表せる。

## 測らずに作る：実物の角をなぞる

現場にプロジェクタがあれば、メジャーで測らずに、壁に映した赤い十字で実物の角をなぞって部屋・箱とプロジェクタの位置・向き・画角を求められる。
カメラは使わず、利用者の目で角に合わせる。仕組みと割り切りは [ADR 0023](decisions/0023-trace-corners-to-reconstruct-venue.md)。

左端のバーの **「なぞる」** を開くと、最初に「会場はもう測って組んでありますか？」と聞かれる。**「いいえ：なぞって作る」** を選ぶと、
次の Step を順に進む。左に手順の一覧、中央の「投影される像」の上に今やること（どこで操作するか・狙う角の模式図・その操作で何が決まるか）が出る。
着いたことのある Step へは一覧から戻れる。なぞった点が残っていれば、開き直しても続きの Step から始まる。

1. **準備**（プロジェクタ本体で・この画面で）。3 つそろうと「次へ」を押せる。
   - プロジェクタ本体の**台形補正（キーストーン）とデジタルズームを切り**、チェックを付ける。光学的なレンズシフト・ズームは使ってよい。
   - **「プロジェクタ出力を開く」** で出力窓を開き、プロジェクタ側の画面で全画面にする（[3章](#3-投影条件を合わせる)の1）。壁に赤い十字が映る。
   - **投射比**（プロジェクタの仕様。投射距離 ÷ 画像の幅）を入れる。正面から壁に向けた配置では、入れないと画角が決まらない。
     ズームレンズなら、いまのズーム位置に近い値を入れる。分からなければ「投射比が分からない」にチェックを付ける（隅を斜めに狙う配置なら、なぞりだけで求まることがある）。
   - 暗い会場では調整用の像を「白」にすると角が見やすい。縦のレンズシフトが分かれば「詳細」に入れる（空欄なら推定する）。
2. **部屋の隅**（壁を見ながら）。十字を実物の角へ運んで確定する。案内と模式図が順に出る：
   床と 2 枚の壁が集まる隅 → そこから上へ伸びる縦の辺の上 → 奥の壁と床の辺の上 → 横の壁と床の辺の上。4 点で次の Step へ進む。
   - 十字の動かし方：出力窓の上でマウスを動かしてクリック／「投影される像」をドラッグして Enter か「この位置で確定」、またはダブルクリック／
     矢印キーで 10 px、Shift＋矢印で 1 px（会場画面と出力窓のどちらでも効く）。
3. **部屋の隅（反対側）**（壁を見ながら）。反対側の隅を同じようになぞる。奥の壁と床の辺の点は、1 つ目の隅を狙えばその点を共有する（近くの点に吸着する）。
   縦の辺どうし・左右の床の辺どうしが平行であることは自動で使う。**この Step は省けない**：隅 1 つでは、投射比があっても縦のレンズシフトが決まらない（#259 で合成会場を使って確かめた）。
   推定が出ると、壁と「投影される像」と「3D会場」に推定した輪郭が出る。輪郭が実物に重なっていれば「次へ」。
4. **箱（任意）**（壁を見ながら）。**「箱の角」**（手前に見える上の角 → その縦の辺が床に着く端 → 上面の 2 本の辺の反対側の端）でなぞり、
   必要なら **「長方形」** で上面や前面の 4 隅を足す。箱は床に置いてあるものとして扱う。いくつでも続けてなぞれる。無ければ「スキップ」。
5. **実寸（任意）**（壁を見ながら）。長さが分かる 2 点（奥の左右の隅など）を、先に長さ（m）を入れてからなぞる。
   入れなくても投影と 3D 練習には使える（全体の縮尺だけが仮）。
6. **確認して適用**（壁を見ながら・この画面で）。ここで初めて像に点の番号が重なり（実出力には出ない）、一覧に点ごとの誤差（px）が出る。
   誤差が他より大きい点は取り違えの候補なので「置き直す」か「削除」する。決まらない量（画角など）があれば理由が出る。
   **「会場に適用」** で、部材とプロジェクタ条件を 1 回の変更として書き込む。手で置いた部材は置き換わる。「直前の変更を戻す」1 回で元に戻る。
   箱や実寸を後から足すときは「追加でなぞる」。

Esc は置き直しやなぞりかけの形を取り消す。「始め方を選び直す」は点を消さずに最初の問いへ戻り、「最初からやり直す」は今のモードの点を消して最初の問いへ戻る。
なぞった点はこのブラウザに会場の下書きとは別に保存され、再読み込みしても残る。書き出す会場ファイルには含まれない。
光が当たっていない角はなぞれない。長方形でない面・曲面・レンズ歪みは扱わない。8 m の部屋で頂点の誤差は 15〜30 cm 程度なので、
仕上げは「立体」の数値欄や[3章](#3-投影条件を合わせる)の微調整で行う。

## 2. 部屋と部材を作る

1. 箱1つから始めるなら「箱1つの会場で作り直す」。部屋から始めるなら「部屋の寸法から作る」に内寸を入力し、「この寸法で会場を作る」を押す。
   床と奥・左右の壁ができる。手前と天井は開放。既存の会場モデルを置き換えるが、マッピングと投影条件は保つ。
2. 3Dビュー上の立体をクリックして選び、「移動」「回転」「サイズ」を選んで色付きハンドルをドラッグする。
   赤=X、緑=Y、青=Z。移動は会場の軸、回転・サイズは立体自身の軸に沿う。サイズは中心を保って変わる。
   小さい部材は「選択に寄る」で拡大する。「スナップ」を有効にすると移動は0.1m、回転は15°刻みになる。
   手を離すと確定・自動保存。Esc、別タブへの移動、画面の終了は操作中の変更を取り消す。
   正確な寸法・位置・角度や名前・色は左側の数値欄で微調整できる。選択は3Dと左側で共通。
   X方向が幅、Y方向が高さ、Z方向が奥行き。変更は投影するモデルの輪郭にも反映する。
3. 「追加する形」で壁・床・箱・四面体・三角柱を選び、「追加」を押す。必要に応じて複製・削除する。部材は最大128個。最後の1個は削除できない。
   「会場変更を戻す」で直前の会場変更を戻せる。
4. 空いた場所をドラッグして視点を回す。大きな会場に変えたら「全体」で画面に収める。
   「編集完了」でハンドルと編集ツールを閉じる。再開はビュー上部の「会場を編集」。
   ハンドルと選択枠は確認用で、実出力・投影背景には入らない。

既存のサンプルやGLBは、編集を開いただけでは置き換わらない。GUIで部材を組み立てるには
箱または部屋から始める。自作・受信した部材の会場は、そのままGUIで再編集できる。

四面体は三角すい、三角柱はY方向に頂部がある形。寸法は回転前の外接直方体の幅・高さ・奥行き、
位置はその**外接直方体の中心**。曲面や頂点単位の編集は使わない。

位置は**部材の中心**。床の上に置く高さ0.6mのステージなら、中心Yは0.3mにする。

| 例 | 寸法 X / Y / Z（m） | 中心 X / Y / Z（m） |
|---|---|---|
| ステージ | 2 / 0.6 / 1.2 | 0 / 0.3 / −1 |
| 柱 | 0.4 / 3 / 0.4 | −2 / 1.5 / 0 |
| 厚さ10cmの床 | 8 / 0.1 / 6 | 0 / −0.05 / 0 |

部屋のひな形は壁厚15cmを内寸の外側、床厚10cmをY=0の下に置く。「会場の寸法」は部材全体の
外形なので、入力した内寸に壁・床の厚みが加わる。個別部材を動かした後に部屋を作り直すと、
その編集はひな形で置き換わる。部材の寸法は直接メートルで扱い、GLB用の全体倍率はかけない。

## 3. 投影条件を合わせる

事前に、プロジェクタ本体の**台形補正（キーストーン）とデジタルズームを切る**。これらが入っていると、
仮想プロジェクタをどう動かしても輪郭が実物に重ならない。光学的なレンズシフト・ズームは使ってよい。

1. **「プロジェクタ出力を開く」** を押し、開いた別窓をプロジェクタ側のディスプレイへ移動して全画面にする
   （別窓で `F` キーまたは全画面ボタン）。全画面にすると、その画面の画素数が出力解像度になり、
   投影アスペクト比もそれに合わせて決まる。全画面にしない場合はツール列の「出力」で実機の解像度を選ぶ。
2. 「グリッド・十字」や「白」で投影範囲を確認する。「黒（ブラックアウト）」は出力を黒にする。
3. 「モデルの輪郭」に戻し、メジャーで測ったレンズの位置と、仕様の投射比から求めた縦画角を「プロジェクタ」に入れる。
4. 壁を見ながら、白い輪郭を壁・床・立体の辺に重ねていく。実機のプロジェクタは動かさず、仮想プロジェクタを動かす。
   頂点を実物の角へ運んで一度に合わせることもできる（[測った会場に合わせる](#測った会場に合わせる頂点を実物の角へ運ぶ)）。
   - **「投影される像」をドラッグ**すると、つかんだ輪郭がポインタについてくる（向きが変わる）。
     Shift＋ドラッグで平行移動、Alt（Option）＋ドラッグで光軸まわりの回転、ホイールで画角、Alt＋ホイールで前後。
   - **キー**（会場画面と出力窓のどちらでも効く）：矢印＝向き、Shift＋矢印＝平行移動、Alt＋↑↓＝前後、
     `[` `]`＝回転、`-` `+`＝画角、`G`＝刻みの切替（粗く 1° / 10 cm ⇔ 細かく 0.1° / 1 cm）、Esc＝操作中の分を取消。
   - キーを連打している間やドラッグ中は表示だけが動き、手を止めると1回分の変更として保存される。
     「直前の変更を戻す」でひとまとまりを戻せる。文字・数値の入力欄にいるときは矢印キーを横取りしない。
   その後「立体」で実測値やGUIハンドルを使って形状を微調整する。
5. 「3D会場」の観察視点を回しても投影位置は変わらない。操作ハンドル・選択枠・プロジェクタのガイドは投影しない。
6. 調整が終わったら **「出力を閉じる」** を押す。別窓を閉じたり、この会場画面を離れたときも調整用出力は終了する。
   出力を開いたまま × で画面を閉じようとすると確認が出る。

部屋の作成だけではプロジェクタの位置や画角は変わらない。遠い会場では描画範囲の「奥の距離」も確認する。
ガイドは位置・向き・投影範囲の目安。選んだ出力の台は水色、他の出力の台は橙で淡く出る。「全体」で全台のガイドごと画面に収められる。
全画面にせず出力窓を拡大しても映像のピクセル数は変わらない。出力解像度は、会場の投影アスペクト比に合う大きさから始まる。
複数出力を含む会場は「プロジェクタ」の「確認する出力」で選択する。調整用出力と微調整の対象は選択した1台分で、他の台は確定済みの値のガイドだけを出す。

調整用の輪郭は仮想プロジェクタから見た形をそのまま出力する。保存済みの2D四隅・crop・maskで変形させない。
モデルと投影条件を合わせた後、通常のマッピングで作品の四隅・crop・maskを調整する。
実際の光量・反射・レンズ歪みを再現する機能ではない。

### 測った会場に合わせる：頂点を実物の角へ運ぶ

会場を実測して組んであれば、輪郭を手で重ねる代わりに、会場の頂点と壁の上の実物の角を対応付けて、
プロジェクタの位置・向き・画角・縦のレンズシフトを推定できる。会場の部材は変えない。推定器は「なぞる」と共通（[ADR 0023](decisions/0023-trace-corners-to-reconstruct-venue.md)）。

左端のバーの **「なぞる」** を開き、**「はい：プロジェクタを合わせる」** を選ぶと、次の 3 つの Step を進む。

1. **準備**（プロジェクタ本体で・この画面で）。台形補正とデジタルズームを切ってチェックを付け、プロジェクタ出力を開いて全画面にする。
   「プロジェクタ」に測ったレンズの位置と画角をおおよそ入れておく。投射比は任意で、入れると画角の推定にも使う。
2. **角を合わせる**（壁を見ながら）。
   - 壁に映った輪郭の角の近くで確定すると、その会場の頂点が選ばれ、十字が頂点の映る位置へ跳ぶ。
     壁の厚みの裏側など、プロジェクタから見て隠れた頂点は選ばない。近くに頂点が無ければ理由が出る。
   - 十字を実物の同じ角へ運んで確定する（十字の動かし方は[「なぞる」](#測らずに作る実物の角をなぞる)の 2 と同じ）。
   - これを**奥行きや面の違う角**で繰り返す（奥の壁の隅・床の手前の角・箱の上の角など）。奥の壁 1 面の角だけでは、画角と距離が切り分けられない。
     必要な点の数は固定していない量で決まり、「n / 必要数」の進み具合が出る（既定で 4 点から推定し、6〜8 点あると誤差が目立つ点が分かる）。
   - **「固定する（推定しない）」**（詳細に畳んである）で、測ってある量（レンズの位置など）を「プロジェクタ」の値のまま固定できる。固定すると必要な点が減る。
     横のレンズシフトは既定で固定する。決まらない量があれば名前が出て、次へ進めない。
3. **確認して適用**（壁を見ながら・この画面で）。像には、推定で頂点が映る位置から確定した点への線と点の番号が重なり（実出力には出ない）、
   一覧に点ごとの誤差（px）が出る。誤差が他より大きい点は、取り違えか会場の寸法の誤差の候補なので「置き直す」か「削除」する。
   **「プロジェクタに適用」** で、プロジェクタ条件だけを 1 回の変更として書き込む。「直前の変更を戻す」1 回で元に戻る。
   点を足すときは「追加でなぞる」で角を合わせる Step へ戻る。対応付け済みの頂点をもう一度選ぶと、その点の置き直しになる。

合わせた点はなぞった点と同じく、このブラウザにだけ保存され、書き出す会場ファイルには含まれない。
「始め方を選び直す」で「なぞって作る」と切り替えても、それぞれの点は残る。「最初からやり直す」は表示中のモードの点だけを消す。

## 4. 会場を配布する

1. ツール列の「会場」で会場に分かりやすい名前を付ける。
2. その下の **「会場だけを書き出す」** を押す。`名前.venue.json` がダウンロードされる。
3. そのファイルを他のユーザーへ渡す。形状・投影条件・マッピングを含み、作品参照や再生順序、
   端末固有のディスプレイ配置は含まない。GLB会場の場合はモデルと埋込画像も含む。

作品参照やスライドショーも含むバックアップには、マッピング側の「パッケージを書き出す」を使う。
会場ファイルはメール添付など任意の方法で配れる。アプリからの公開・クラウド同期は行わない。

## 5. 受け取った人が使う

自分の作品またはスライドショーで「マッピング」を開き、左端のバーの「3D」→
**「会場ファイルを読み込む」** で会場ファイルを選ぶ。「プロジェクト」の読込ボタンも利用できる。
現在の作品・再生設定を保ちながら、会場・投影条件・マッピングを読み込む。
再調整するときは受信側も「会場の作成・調整」で読み込み、部材を追加・複製・編集できる。不正なファイルは現在の会場を置き換えない。

作品がまだなければ、[内蔵サンプル](https://dropcaster.soui.dev/mapping)から始められる。
[8m×6mの会場サンプル](samples/room-8x6.venue.json)はそのまま取り込める。

新しい保存形式は Project v3 / Venue package v2。配布先も最新版を使う。
以前のProject v1/v2・Venue package v1、旧2D設定v2、GLBの読込は継続して対応する。
曲面や複雑な模型が必要な場合は、外部の3Dツールで作った静的GLBを「会場の作成・調整」の左端の「ファイル・設定」→「GLB会場を読み込む」から使える。
